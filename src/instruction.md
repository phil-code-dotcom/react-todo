Todo Application using React Hooks

Objective: Build a functional Todo Application using React and the useState hook.

Functional requirements

Users must be able to add new tasks.

Users must be able to view all tasks.

Users must be able to delete individual tasks.

Users must be able to edit existing tasks.

Users must be able to mark tasks as completed.

Users must be able to see the total number of tasks.

Users must be able to see the number of completed and pending tasks.

Empty task submissions must not be accepted.

Technical requirements

Use React with Vite.

Use functional components.

Use the useState hook.

Use the map() method to display tasks.

Use the filter() method to delete tasks.

Use the spread operator when updating state.

Use unique IDs for every task.

Do not manipulate the DOM directly.

Do not use external state-management libraries.

Bonus challenges

Add LocalStorage so tasks remain after refreshing the page.

Add filters for All, Completed and Pending tasks.

Add a confirmation before deleting a task.

Make the application responsive on mobile devices.

Important: Write your own code. Do not copy a complete Todo Application from the internet or AI. You should be able to explain every function and state update in your project.
